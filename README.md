## Technology Stack

- **Backend Framework**: FastAPI (Python)
- **Database**: PostgreSQL
- **Authentication**: JWT (JSON Web Tokens)
- **Validation**: Pydantic
- **Documentation**: Swagger/OpenAPI (auto-generated)
- **Database Driver**: psycopg3 (raw SQL - no ORM)

## Backend
- Backend can be accessed inside of the BLG317E-PROJECT/backend folder. Additionally, the backend folder has its own README.md file which gives the necessary instructions on how to get the project running on your own machine. Lastly, DATABASE.md file inside of the backend folder has further instructions on how to initially setup the database, how to reset the database, and the login information for a couple of mock users.

## Frontend
- Frontend can be accessed inside of the BLG317E-PROJECT/frontend folder. However, the frontend is still a Work In Progress and as such some portions are not yet implemented.
